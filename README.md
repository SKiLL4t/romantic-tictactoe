# 💝 Романтические крестики-нолики для Аленочки 💝

Романтическая онлайн-игра в крестики-нолики, где вместо крестиков - сердечки (❤️), а вместо ноликов - цветочки (🌸).

## Как играть

1. Откройте игру по ссылке: [Romantic Tic-Tac-Toe](https://your-username.github.io/romantic-tictactoe)
2. Введите своё имя
3. Создайте новую игру или присоединитесь к существующей:
   - Чтобы создать игру, нажмите "Создать новую игру" и отправьте код партнеру
   - Чтобы присоединиться к игре, введите полученный код и нажмите "Присоединиться"
4. Играйте и наслаждайтесь! ❤️

## Особенности

- Красивый романтический дизайн
- Анимированные сердечки и цветочки
- Сохранение статистики игр
- Простой 4-значный код для подключения
- Работает на компьютерах и телефонах
